# KC Frontend WordPress Theme

A custom WordPress theme built from scratch using HTML, CSS, and JavaScript.

## Features
- Custom theme structure (header, footer, index)
- WordPress Loop for post rendering
- JavaScript-powered dark mode toggle
- Persistent user preference using localStorage
- Clean and minimal UI

## Tech Stack
- WordPress (Theme Development)
- HTML, CSS
- JavaScript (DOM manipulation, localStorage)

## What I Learned
- WordPress theme file structure
- The WordPress Loop
- Enqueuing assets properly using functions.php
- Handling CSS specificity with WordPress core styles
- Debugging frontend issues in a CMS environment

## Setup
1. Copy the theme folder into `wp-content/themes/`
2. Activate from WordPress Admin → Appearance → Themes
